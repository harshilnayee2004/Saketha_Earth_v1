# Saketha Earth — Luxury Architectural Landholdings & Estates

An architectural luxury real estate portal engineered with 3D spatial depth hero animations, interactive CAD floor blueprints, cadastral vector coordinate mapping, capital milestone roadmaps, and daytime 3D clouds.

## Features
- **3D Villa Depth Hero**: Multi-layer spatial text emergence behind architectural villa foreground during viewport scroll.
- **Curated Architectural Showcase**: 4-card editorial bento grid featuring CAD floor plans with room hotspots and vector cadastral mapping.
- **Capital Allocation Roadmap**: Structured milestone release schedule with interactive dossier inquiries.
- **The Master Collection**: Curated portfolio of limited-edition estates, waterfront villas, and agro-sanctuaries.
- **VIP Chauffeur Service**: Direct concierge inspection booking with luxury doorstep pickup.
- **Atmospheric 3D Cloud Portal**: Vanta.js interactive 3D cloud atmosphere with daytime sky transitions.

## Quick Start
Open `index.html` directly in any modern browser, or run a local HTTP server:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000`.
